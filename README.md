# Dino Runner

Бесконечный раннер как в Chrome: динозавр, кактусы, птеродактили, смена дня и ночи.

**Играть:** https://yesetsissenov.github.io/dino_game/ (GitHub Pages)

## HTML5-версия (основная)

Вся игра — один файл `index.html` без зависимостей. Просто откройте его в браузере.

Возможности:

- Пиксель-арт спрайты, плавная смена дня/ночи (звёзды, луна, облака)
- Прыжок с переменной высотой (держите дольше — прыжок выше), приседание
- Птеродактили на трёх высотах: перепрыгнуть, присесть или пробежать под ними
- Управление с клавиатуры и с тачскрина (тап — прыжок, нижняя треть экрана — присесть)
- Звуковые эффекты (WebAudio, без файлов), кнопка мьюта
- Рекорд сохраняется в localStorage, отметка каждые 100 очков
- Пауза (P) и автопауза при сворачивании вкладки

### Управление

| Действие | Клавиши | Тачскрин |
|---|---|---|
| Прыжок | Space / ↑ / W | тап |
| Присесть | ↓ / S | удерживать нижнюю треть экрана |
| Пауза | P | — |
| Звук вкл/выкл | M | кнопка 🔊 |

### Отладка

Хэш-параметры для тестов и скриншотов: `#demo` — автостарт, `#demo-night` — сразу ночь, `#demo-ff600` — промотать 600 кадров.

## YouTube Playables

Игра готова к упаковке для [YouTube Playables](https://developers.google.com/youtube/gaming/playables): один HTML-файл, работает офлайн. Для сертификации нужно подключить их SDK (`https://www.youtube.com/game_api/v1`) и заменить объект `storage` в `index.html` на `ytgame.game.saveData/loadData`, добавив вызовы `firstFrameReady()`/`gameReady()`.

## Легаси: версия на Pygame

Исходная десктопная версия лежит в `src/` (Python + Pygame):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m src.main
```
